# Bill of materials

`bom.xlsx` is the bill of materials and its single source of truth. Copy it to track your own
build. It has these sheets:

- **Summary**: totals per group and per phase, each split into owned, ordered and still to buy.
  All are formulas, so they follow your edits.
- **One sheet per group** (Actuators, Hands, Compute & sensors, Power, Electronics & wiring,
  Structure & materials, Fasteners, Tooling, Safety). Each line has an id, item, phase, a
  **Status** dropdown (to buy, ordered, owned), quantity, unit price, a line total (formula),
  where the price came from, a source link and notes. Owned lines keep their price, so the total
  stays the full cost to replicate.
- **Sourcing**: where each researched item is sold (official store first, then distributors),
  with links, prices, tiers, availability, the date checked and whether the price was confirmed.
- **Made parts (CAD)** and **Actuator bolts (CAD)**: generated by `python -m cad.export` from the
  CAD. CI checks that they are current. Their Status and Build notes columns are yours, and the
  export keeps them.

## Editing

`tools/bom_book.py` keeps the workbook consistent. Either edit the workbook by hand (add a row
anywhere in a group's sheet, or change a status, price or source) and then tidy it:

```bash
python tools/bom_book.py            # re-sort, re-format, rebuild formulas, dropdowns and Summary
```

Or edit it from the command line, which tidies it as well:

```bash
python tools/bom_book.py set cells unit_usd=9.95 "price_basis=dealer 2026-11-02"
python tools/bom_book.py add usb-hub group=electronics "item=USB 3 hub" qty=1 unit_usd=30 phase=P4
python tools/bom_book.py source cells "vendor=Some dealer" url=https://example.com unit_usd=9.95
python tools/bom_book.py set compute status=owned
python tools/bom_book.py remove usb-hub
```

`python tools/bom_book.py --check` (CI) fails if a line is invalid (unknown status or group,
duplicate id, a sourcing row without its line) or if the workbook isn't tidy.
`python tools/bom_summary.py` prints the totals. Sheets the tool doesn't manage are left alone. A
workbook saved by a spreadsheet program may need one tidy run before `--check` passes again.
Totals are computed when the file is opened (in Excel or LibreOffice). Previews that don't
compute formulas show them empty.

## Cost

At October 2026 prices the full robot comes to about **$17.5k** (`tools/bom_summary.py`). Phase 2
is about $1.0k, phase 3 $3.2k, phase 4 $9.1k, phase 5 $3.8k and phase 6 $0.4k. By group:
actuators $6.2k, compute and sensors $4.7k (the Jetson AGX Orin 64 GB developer kit alone is
$3,499, up from $1,999 before NVIDIA's July 2026 price rise), structure and materials $2.6k,
power $1.6k, and the rest $2.4k. Owned items (the developer kit, the two AmazingHand kits and a
USB IMU) carry their current price, so the total is what a replicator pays. This build already
owns $3.7k of it and has about $13.8k still to buy.

Not counted:
- **Desktop GPU for training (optional).** Isaac Lab training and GR00T fine-tuning want an RTX
  card with 24-32 GB. The RTX 5090 lists at $1,999, but in late 2026 it sold for about $4,000 or
  more. A rented cloud GPU works too.
- The desktop CNC mill and 3D printer (R60), shipping, import duties and tariffs. Most actuators
  and the hand kits ship from China.

## Price basis

Prices and links are indicative only. Each one is what a listing showed on the date given in its
Price basis column, often from a reseller and not confirmed with the maker (marked unverified or
"estimate"). Lines marked "estimate" have no listing behind them yet: online machining, the IMU,
the charger and most power and wiring parts. They are not quotes or endorsements. The project
has no affiliation with any vendor and earns nothing from these links. Check current prices,
specifications and import costs before buying.
